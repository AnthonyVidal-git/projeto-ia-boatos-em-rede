# Projeto de Inteligência Artificial: Boatos em Rede

Simulação da propagação de fake news com agentes inteligentes, feita no Google Colab para a disciplina de Inteligência Artificial.

## O que é

300 eleitores-agentes conectados numa rede social trocam uma notícia falsa. Cada eleitor está em um de três estados: suscetível, espalhador ou cético. Ao rodar a simulação, vemos o boato viralizar ou morrer.

Testamos três defesas: checagem de fatos, limite de encaminhamento e letramento midiático.
